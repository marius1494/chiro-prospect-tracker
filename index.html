GitHub-Sync

Mit einem persönlichen Zugriffs-Token wird jede Änderung automatisch nach GitHub gespeichert — dein Kollege sieht sie nach spätestens ~20 Sekunden. Ohne Token ist die Seite nur zum Lesen / lokal.

1. Fine-grained Token erstellen
2. Repository access → „Only select repositories" → chiro-prospect-tracker
3. Permissions → Repository permissions → Contents → Read and write
4. Token generieren, unten einfügen, „Speichern & verbinden".

Der Token wird nur in diesem Browser gespeichert (localStorage) und ist auf dieses eine Repo begrenzt. Jederzeit auf GitHub widerrufbar.
